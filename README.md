# Sistema de Controle de Horas Extras

Aplicação desenvolvida em linguagem C com o objetivo de gerenciar o registro de horas extras de funcionários por meio de um sistema simples baseado em menu interativo no terminal.

## Funcionalidades

* Cadastro de funcionários
* Registro de horas extras individuais
* Exibição de relatório com total de horas por funcionário
* Interface interativa via terminal

## Tecnologias

* Linguagem C
* Biblioteca padrão (`stdio.h`, `stdlib.h`, `string.h`)

## Objetivo

Demonstrar conceitos fundamentais de programação estruturada, manipulação de estruturas (`struct`), controle de fluxo e interação com o usuário em aplicações de linha de comando.
